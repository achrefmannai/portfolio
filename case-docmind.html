Overview

DocMind is a generative AI assistant that enables natural language querying over a company’s internal knowledge base. It combines semantic retrieval with generative reasoning to deliver accurate, contextual answers — complete with source citations.

The system ingests PDFs, Word docs, and markdown files, chunks them intelligently, and stores embeddings in a vector database. At query time, it retrieves the most relevant passages, then uses a chain‑of‑thought prompt to synthesize a final answer.

Key features

  • Hybrid search (dense + sparse) for higher recall
  • Fine‑tuned embeddings on domain‑specific corpora
  • Chain‑of‑thought reasoning with source attribution
  • Async ingestion pipeline with progress tracking
  • REST API with streaming responses

Architecture

The backend is built with FastAPI and LangChain, using Pinecone as the vector store. Document ingestion is handled by a background worker that splits, embeds, and indexes content. The frontend is a lightweight React dashboard that streams answers in real time.

We also implemented a caching layer and query routing to reduce latency, and added feedback loops to continuously improve retrieval quality.
