From natural language to relational schema

Automatic generation of SQL schemas from simple user prompts using LLMs, RAG, and reasoning architectures.

LLM RAG Reasoning Prompt Engineering

Overview

This project demonstrates how generative AI can interpret a simple natural language request and automatically produce a fully structured SQL schema with proper constraints, primary keys, and relationships.

The system takes a prompt like "Create a database. Each user has name, age, profession. Each user has credentials (username, password)" and generates a complete JSON representation of the database schema — including tables, columns, data types, constraints, and foreign key relationships.

The Prompt

"Create a database. Each user has - name - age - profession Each user has credentials - username - password"

Key Features

  • Automatic inference of primary keys and foreign keys
  • Detection of uniqueness constraints (UNIQUE)
  • Relationship mapping (one-to-one, one-to-many, many-to-many)
  • Appropriate data type selection based on intent
  • Structured JSON output ready for integration

How It Works

The system uses a RAG architecture combined with a reasoning model to interpret the user's intent. It identifies entities, attributes, and relationships from the natural language prompt, then applies database design best practices to generate a coherent schema.

The model infers that "user" is an entity, "name/age/profession" are attributes, and "credentials" is a related entity with a one-to-one relationship. It automatically assigns a primary key to each table and links them appropriately.
